Настройка GitHub за 2 минуты

  1. 1. Создай приватный репозиторий: github.com/new → имя hydra-backups → Private → Create
  2. 2. Создай токен: fine-grained token → Repository access: Only select → выбери hydra-backups → Permissions → Add permissions → Contents: Read and write → Generate
  3. 3. Скопируй токен (github_pat_...), вставь в форму ниже, нажми «Проверить», затем «Сохранить»

Токен хранится в панели зашифрованно (AES-256, master-key отдельно от БД). В бэкап попадает только зашифрованный blob — без master.key он бесполезен.
